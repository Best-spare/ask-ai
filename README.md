# 智问 AskAI

基于 Next.js + AI 的知识问答平台

## 技术栈

- **框架**: Next.js 14+ (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **UI 组件**: shadcn/ui
- **数据库**: Supabase (PostgreSQL)
- **AI**: OpenRouter + Vercel AI SDK
- **认证**: Clerk

## 项目结构

```
ask-ai/
├── .trae/              # Trae AI 配置
├── app/                # Next.js App Router 页面
├── components/         # 组件
├── lib/                # 工具库
├── public/             # 静态资源
├── .gitignore          # Git 忽略文件
├── .env.example        # 环境变量模板
├── package.json        # 项目依赖
└── README.md           # 项目说明
```
